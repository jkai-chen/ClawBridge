# ClawBridge agent skill

Provider-neutral instructions for an agent connected to an existing ClawBridge
workspace. The skill does not install the binary, create a bus, or grant permission
to act outside the human's task. `clawbridge skill install` installs this folder for Claude Code and Codex. Otherwise,
install it with your agent's skill installer or point the agent's instructions at
SKILL.md.

The package includes the root SKILL.md, references, UI metadata for Codex, and
its MIT licence (the same as ClawBridge's).
