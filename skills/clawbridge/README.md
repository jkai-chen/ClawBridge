# ClawBridge agent skill

Provider-neutral instructions for an agent connected to an existing ClawBridge
workspace. The skill does not install the binary, create a bus, or grant permission
to act outside the human's task. Install this folder with your agent's skill
installer or point its instructions at SKILL.md.

The package includes the root SKILL.md, references, UI metadata for Codex, and a
licence-status file. The project owner has not selected a distribution licence.
